# Global Infectious Disease Outbreak Analysis

## Project Overview

This project explores global infectious disease outbreak records to identify patterns across diseases, countries, years, and disease categories.

Using Python and data visualization techniques, the analysis examines how reported outbreak records are distributed geographically and over time.

## Objectives

- Identify the 15 most frequently reported infectious diseases.
- Determine the countries with the highest numbers of reported outbreak records.
- Analyze global outbreak trends over time.
- Examine the distribution of outbreaks by disease category.
- Explore temporal patterns across frequently reported diseases.
- Visualize the geographical distribution of outbreak records worldwide.

## Dataset

The dataset contains reported infectious disease outbreak records with the following variables:

| Column | Description |
|---|---|
| Country | Country associated with the outbreak record |
| Year | Year of the reported record |
| Type of disease | Disease category |
| Disease | Name of the infectious disease |

## Limitations

- The analysis is based on reported records available in the dataset.
- Differences in reporting systems may influence country-level comparisons.
- The number of records should not be interpreted as the number of infected individuals.
- The analysis identifies patterns but does not establish causal relationships.
